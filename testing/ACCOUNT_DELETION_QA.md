# アカウント削除 QA手順

最終更新: 2026-10-04

マイページ下部の「アカウントを削除」(`components/DeleteAccountSection.tsx` / `lib/auth/deleteAccount.ts`)の手動QA。
Apple App Store Guideline 5.1.1(v)対応。

## 絶対に守ること

- **審査用(Review)アカウントでは絶対に試さない。** 削除するとサンプルデータごと消え、Appleが審査できなくなる。
  QA専用に、使い捨てのGoogleアカウント(またはApple ID)を使う。
- 動作確認の前に、**`firestore.rules`をFirebase Consoleへ手動で公開する**
  (`users/{userId}`の`allow delete`を本人に許可した変更が必要。未公開だと削除が`permission-denied`で失敗する)。
  この変更は「本人が自分のプロフィールを消せる」だけで、既存機能への影響はない。

## 事前準備(使い捨てアカウントでデータを作る)

1. 使い捨てアカウントでログイン
2. ほしいリスト1件、マイコレクション1件、マイデッキ1件、ブロック1件(別アカウントの投稿をブロック)
3. トレード投稿1件、他の投稿へのコメント1件

## 確認項目

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | マイページ最下部に「アカウントを削除」が出る(Web・iOSアプリ両方) | 表示される |
| 2 | ボタン → モーダルが開く | 削除対象と残るもの(通報・ご意見フォーム)が説明されている |
| 3 | 「キャンセル」 | 何も削除されず閉じる |
| 4 | 「削除する」→ 再ログイン画面でキャンセル | 削除されず、モーダルに戻る(エラー表示なし) |
| 5 | 「削除する」→ **別のアカウント**で再ログイン | 「別のアカウントが選択されました」と表示、何も削除されない |
| 6 | 「削除する」→ 同じアカウントで再ログイン | 「削除しています」→「アカウントを削除しました」 |
| 7 | 「ホームへ」 | ホームに戻り、ログアウト状態になっている |
| 8 | Firebase Console → Authentication | そのユーザーが消えている |
| 9 | Firebase Console → Firestore | `users/{uid}`(プロフィールと4つのサブコレクション)、そのユーザーの`tradePosts`、`comments`が消えている |
| 10 | トレード掲示板(ログアウト状態) | 削除したユーザーの投稿・コメントが表示されない |
| 11 | 同じアカウントで再ログイン | 新規アカウントとして始まり、データは空 |
| 12 | (iOSアプリ・Appleでサインイン)同じ手順 | 6〜11が同様。可能ならAppleのトークン失効がエラーにならないこと(Safariコンソール/Xcodeログで`Apple token revocation failed`が出ていないか) |

## 残るデータ(仕様)

- `reports`: 通報した記録。ルール上、クライアントから削除できない。アカウント削除後は本人と結びつかない
- `feedback`: 意見・要望フォームの送信内容(任意入力の連絡先を含む)
- 他のユーザーが、削除したユーザーの投稿に付けたコメント(投稿が消えるため表示されなくなるが、データ自体は残る)

これらはプライバシーポリシー(`app/privacy`)と削除モーダルに明記している。
