# 回帰テストチェックリスト

最終更新: 2026-10-02

**現状、`package.json`に自動テスト（`test`スクリプト等）は存在しない。** 以下の項目はすべて**MANUAL**（手動確認）である。
各項目は過去のインシデント（[[../operations/INCIDENTS.md]]）を踏まえて選定している。
リリース前チェックリスト（[[../operations/RELEASE_CHECKLIST.md]]）と併用すること。

## AUTH（MANUAL）

- [ ] 匿名ログイン（ゲスト状態）でアプリが使える
- [ ] Googleログインが成功する（Web・Android・iOSそれぞれで）
- [ ] Appleログインが成功する（Web・iOSそれぞれで）
- [ ] ログアウトが正常に動作する
- [ ] ゲスト状態で何か操作（コメント投稿等）した後にログインし、データが引き継がれる（匿名アカウントのリンク）
- [ ] ログイン済み状態で、ほしいリスト・マイコレクション・マイデッキ・トレード投稿・コメント投稿が**実際に**成功する（[[../operations/INCIDENTS.md]]のINC-003は「ログイン自体は成功するがFirestore操作は全滅」というパターンだったため、ログイン成功だけでは確認不十分）

## CORE（MANUAL）

- [ ] カード検索（キーワード）が動作する
- [ ] フィルター（タイプ・レアリティ等の複数条件）が動作する
- [ ] カード詳細ページが正しく表示される（画像・技・特性・入手方法）
- [ ] パック一覧・パック別カード一覧が表示される
- [ ] 日本語ラベル（ポケモン名・技名・特性名・効果文）が正しく表示される

## ACCOUNT（MANUAL）

- [ ] ほしいリストへの追加・削除
- [ ] マイコレクションの枚数増減（1〜3、3枚以上表示、0枚でドキュメント削除）
- [ ] マイデッキの作成・編集・削除（3デッキ制限、20枚制限、たねポケモン必須等のバリデーション）
- [ ] マイページのプロフィール・統計・投稿プレビュー表示

## COMMUNITY（MANUAL）

- [ ] トレード投稿の作成・編集・募集終了切り替え
- [ ] コメント投稿（ログイン必須）・削除（投稿者本人のみ）
- [ ] 未ログイン状態でのトレード掲示板・コメント閲覧（閲覧は制限なしであることの確認）

## ANDROID（MANUAL）

- [ ] ネイティブGoogleログイン（実機、できればPlay App Signing署名済みビルドで）（[[../operations/INCIDENTS.md]]のINC-001）
- [ ] 端末の戻るボタンでアプリが終了せず正しく画面遷移する（[[../operations/INCIDENTS.md]]のINC-002）
- [ ] 起動スプラッシュ画面の表示
- [ ] 下タブバーでの画面遷移

## iOS（MANUAL）

- [ ] ネイティブApple Sign-In（実機/TestFlight）
- [ ] Googleログインが退行していない
- [ ] 起動スプラッシュ画面の表示
- [ ] ピンチズーム無効化の挙動（意図した仕様）
- [ ] iPhone専用設定（iPadでの表示崩れが無いか、または非対応である旨が正しく扱われているか）

## INFRA（MANUAL）

- [ ] 本番URL（https://pocket-base-delta.vercel.app）が実際に開ける（[[../operations/INCIDENTS.md]]のINC-004のような一時停止が起きていないか）
- [ ] Vercelダッシュボードで直近のCPU/使用量に異常な急増が無いか確認
- [ ] 主要APIパス（Firestore読み書きを伴うページ）がエラーなく応答する

---

**運用ルール**: 新しいインシデントが発生し再発防止チェックが必要になった場合、このファイルに項目を追加する。
自動テストを将来導入する場合も、このチェックリストを出発点にテストケースを設計するとよい。
